# 🏥 Smart Hospital Management System | Power BI, DAX, Power Query

An interactive relational BI solution built to analyze hospital operations, patient metrics, and financial performance across multiple departments.

---

## 🚀 Project Overview
This project consolidates **13,000+ records** across six related hospital tables (patients, appointments, billing, doctor feedback, and department logs) into a single centralized Power BI report to give stakeholders comprehensive visibility into institutional performance.

---

## 🛠️ Tech Stack & Tools
* **BI & Visualization:** Power BI, Power Query, DAX
* **Data Modeling:** Relational Star/Snowflake Schema Design
* **Data Sources:** Multi-table relational hospital datasets

---

## ✨ Key Features & Architecture
1. **Relational Data Modeling:** Cleaned and transformed raw data using Power Query, establishing a 6-table relational model across 4 branches and 8 departments.
2. **Advanced DAX Measures:** Developed custom DAX calculations for revenue, average billing per patient, appointment completion rates, cancellation percentages, and doctor ratings.
3. **Multi-Dashboard Executive Report:** Built a comprehensive 6-page interactive report covering Executive Summary, Patient Demographics, Doctor Performance, Department Breakdown, Financial Analytics, and Appointment Tracking.
